# Installing Nimbus

![The Nimbus command line](./images/logo.jpg)

> **Beta.** Nimbus 0.1 is an early preview. Commands and flags will change.

Nimbus ships as a single binary. Download it with the install script:

```bash
curl -fsSL https://get.nimbus.dev/install.sh | sh
```

Then confirm it runs:

```bash
nimbus --version
# nimbus 0.1.0 (beta)
```

There are no other dependencies. The binary is self-contained.
